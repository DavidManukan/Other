# Solver

Бот в WhatsApp: получает фото или PDF с заданием, решает через Claude и присылает решение картинкой, как страницу тетради (чёрный фон, белый текст, формулы набраны). Работает на Cloudflare Workers, сообщения ходят через GREEN-API.

Старый `solver.ts` (версия для Val Town) лежит рядом и в новой версии не используется.

## Как включить

1. Cloudflare → Workers & Pages → воркер `solver` → Settings → Builds: репозиторий этот, ветка `claude/solver-bot`, поле Build command пустое, Deploy command `npx wrangler deploy`.
2. Settings → Variables and Secrets воркера (не в разделе Builds) → добавить как Secret: `ANTHROPIC_API_KEY`, `GREEN_URL`, `GREEN_ID`, `GREEN_TOKEN`. Желательно ещё `OWNER`: свой номер цифрами, без плюса и пробелов.
3. Открыть ссылку воркера. Страница сама проверит ключи, рендер и браузер и переведёт вебхук GREEN-API на новый адрес. Когда все строки зелёные, бот работает.
4. Написать боту `ping`.

Ключи в код не пишутся: только в Variables and Secrets.

## Команды в чате

Всем:
- `ping`: жив ли бот и какие у него настройки
- `решай`: не ждать следующее фото, решать сейчас
- `стоп`: остановить текущую работу
- `сброс`: забыть разговор и прошлые фото
- `картинкой` / `текстом`: вид ответа

Хозяину:
- `быстро` / `средне` / `умно` / `макс`: сколько модель думает
- `fast вкл` / `fast выкл`: быстрый режим (ответ пишется быстрее, токены вдвое дороже)
- `проверка вкл` / `проверка выкл`: вторая, независимая проверка готового решения
- `расход`: сколько потрачено на Claude сегодня, вчера, за 7 и 30 дней
- `лимит 3` / `лимит выкл`: дневной потолок расходов в долларах
- `доступ закрыть` / `доступ открыть`: отвечать только хозяину или всем (закрыть можно, только когда задана `OWNER`)

Хозяин это чат из `OWNER`. Если переменной нет, хозяином становится первый чат, который написал боту `ping`.

## Необязательные переменные

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `MODEL` | `claude-fable-5-2` | основная модель |
| `FALLBACK_MODEL` | `claude-opus-5-5` | запасная, если основной нет на ключе |
| `EFFORT` | `high` | сколько модель думает: `low`, `medium`, `high`, `xhigh`, `max` |
| `FAST` | выкл | `1` включает быстрый режим |
| `CODE` | вкл | `0` выключает пересчёт вычислений кодом |
| `CHECK` | вкл | `0` выключает вторую проверку решения |
| `CHECK_MODEL` | запасная модель | модель для второй проверки |
| `PAGES` | вкл | `0`: всегда отвечать текстом, без картинок |
| `AUTO_MAX` | `5` | сколько раз продолжать оборванный длинный ответ |
| `REGION` | `eu` | регион, из которого идут запросы к Claude |
| `GREEN_MEDIA_URL` | угадывается | адрес загрузки файлов из консоли GREEN-API, если бот не угадал его сам |

## Проверка кода

```
npm install
npm test              # модульные тесты
npm run e2e           # сквозные проверки на локальном воркере с имитацией GREEN-API и Claude
npm run e2e:browser   # настоящий браузер снимает страницы решения
npx tsc --noEmit
```
